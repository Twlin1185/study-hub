## 목표

끝났을 때, ChatGPT 구독만 있는 사용자가 **API 키도 터미널도 모른 채** 설정 화면에서 [Codex 설치] → [로그인 확인]을 눌러 온보딩을 마치고, 파일 반입·변환을 Claude 사용자와 동일한 UX로 완주한다.
