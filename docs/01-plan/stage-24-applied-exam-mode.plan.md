## 현행 실측 (2026-08-04 — 상세는 plan §14 F50·§4.21이 정본, 여기는 요지)

- **일반 반입의 태그·개념연결**: 태그 = 변환 LLM 1회 출력의 `tags` 배열(commit 시 `get_or_create_tag`→DocumentTag — 별도 호출 0) · "개념연결" = 같은 출력의 `suggest_relations`(preview 승인 → `document_relations('explains','import')`). **F21 태그 규칙(`tag_rule_service.scan_document`) = 순수 규칙 기반(LLM 0)** — 태그만 있으면 분류 연결 제안이 공짜로 따라온다(auto 규칙은 즉시 연결(linked), suggest 규칙은 제안(suggested)).
- **응용 생성물 현황**: `applied_exam_service`에 태그·suggest_relations 처리 0줄 — §4.21 저장 4-ⓒ "태그 미부여"·격리 규약이 의도적으로 배제(규칙 자동 연결로 본류 유입되는 뒷문 차단). 근거 연결은 `document_relations('derived_from','applied_exam')`로 이미 존재(LLM 0 — 리포트 근거 링크).
- **개정의 열쇠**: "태그 미부여"의 실질은 **승인 없는 자동 연결 차단**이었다 — 태그를 부여하되 규칙 연계를 **제안 강제**로 묶으면 그 실질은 그대로 지켜진다(§4.21 S24 블록 개정 근거).

## 목표

끝났을 때, AI 응용 생성 시작 화면에서 **[누적(기본)/1회성]**을 고를 수 있고 — 누적이면 생성 문항에 태그가 붙어 탐색·검색·태그 규칙 **제안**(승인 경유)으로 이어지며, 1회성이면 태그 없이 종전과 완전히 같게 동작한다. 어느 모드에서도 문서 저장·격리 분류·`[AI 생성 문항]` 마커·일반 퀴즈/SRS 기본 제외·근거 연결(derived_from)은 불변이고, **사람 승인 없이 실전 트리에 자동 연결되는 경로는 0**이다(auto 규칙도 응용 생성물에는 제안 강제). 추가 LLM 호출은 0이고(태그는 같은 생성 호출의 출력), DDL·Alembic·신규 엔드포인트도 전부 0이다.

## DoD (완료 정의)

**자동 검증 가능 항목**:

1. **모드 계약**: 미지정 = accumulate, oneshot = 종전 동작과 회귀 수준 동일(태그 0·스캔 0), 오류값 = 422.
2. **누적 = 태그·제안**: accumulate 생성물에 태그가 저장되고 태그 규칙 매칭이 **전부 suggested**로만 생성된다 — auto 규칙 포함 자동 연결(linked) 행 0(격리 원칙 유지 — R22).
3. **추가 비용 0 구조**: 태그는 생성 호출의 출력 필드 — mode와 무관하게 LLM 호출 횟수 동일(추가 호출 0).
4. **격리·채점 불변**: 문서 저장·격리 분류·마커·일반 퀴즈/SRS 기본 제외·derived_from·채점 트랜잭션이 양 모드에서 종전과 동일.
5. **DDL 0건·Alembic 0건·신규 엔드포인트 0개**(§4.21 S24 재확인 — 어긋나면 착수 중단 후 보고).

**사용자 이행 항목** (실 LLM 비용):

6. **누적 모드 실생성 1회**: 태그 품질 표본(부여 태그의 적절성·제안함 연계 동작) 확인 — 결과를 완료 기록에 기입.

## 이 단계에서 하지 않는 것

- **자동 연결(linked) 허용 없음** — 응용 생성물의 태그 규칙 매칭은 auto 규칙이어도 제안 강제(격리 원칙 — 재제안 시 근거 필요).
- **`suggest_relations`류 신규 개념연결 제안 없음** — 사전 미리보기 부재로 승인 지점이 없다(기존 derived_from으로 충족 — YAGNI).
- **기존 생성물 태그 소급 없음** — 별도 LLM 비용(수동 태그 편집으로 갈음 — 실수요 확인 시 계획서 먼저).
- **1회성의 문서 미저장(일회용) 없음** — F45 결정 ① 기각 유지(불변 규칙 2 — 오답 복습 루프가 실문서를 참조).
- **1회성 런의 자동 정리·만료 없음** — 삭제는 기존 분류 관리·소프트 삭제 경로 그대로(YAGNI).
- **F25 실전·일반 퀴즈 계약 변경 없음** — 분류 격리로 자연 제외 구조 불변.

## 리스크

- **격리 침식 경계(R22 연장)**: 태그 부여로 생성물의 노출면이 넓어진다(태그 탐색·검색) — 마커 상시 표기·제안 강제·격리 분류가 방어선. 검토에서 "linked 행 0" 중점 확인.
- **suggested 강제 플래그의 파급**: `scan_document` 호출부 옵션이 일반 반입 경로의 규칙 의미론(auto = 즉시 연결)을 건드리면 안 된다 — 기본값 무변경·응용 호출부만 플래그(회귀 테스트로 고정).
- **기본값 변경 인지**: accumulate 기본은 종전(태그 없음)과 다른 동작 — 매뉴얼·UI 1줄 설명으로 정직 고지(조용한 동작 변경 아님을 문서로).
