> **F34 LLM 엔진 관리** (v1.x 확정 후보 — 2026-07-24 실사용 429 경험으로 범위 확정. **이중 엔진 + 우선순위 + 폴백** 구조, 사용자 확정):
> 1. **엔진 2종 등록**(설정 화면, 카드 2개):
>    - **CLI 카드**: 설치·로그인·호출 가능 진단 + 마지막 성공/실패 시각 + 한도 상태. 로그인은 앱이 대행 불가(대화형 브라우저 절차) — "터미널에서 `claude` 실행해 로그인" 단계 안내 + [다시 확인] 재검사 버튼의 안내형 마법사.
>    - **API 카드**: 키 등록 UI(입력 시 즉석 연결 테스트, 이후 마지막 4자리만 마스킹 표시, write-only). **키 저장은 settings/DB 금지** — 루트 별도 로컬 파일(예: `secrets.json`, .gitignore + 백업(F27) 제외 대상)에 저장해 백업·git으로 키가 복제되는 것을 원천 차단. 환경변수/`ant auth login` 프로필이 있으면 그것을 우선 인식(키 파일 불필요).
> 2. **우선 엔진 선택**(CLI↔API) + **폴백 정책**: 우선 엔진이 한도 초과·타임아웃이면 보조 엔진 시도 — 방식은 **자동**(API 과금 발생 안내에 명시 동의한 경우만) / **물어보기**(기본값 — "API로 계속할까요?" 확인창) / **끔**(A방식 수동 반입 안내). API는 건별 과금이므로 조용한 자동 폴백 금지.
> 3. **오류 구조화** — convert/regenerate 잡 실패 시 CLI/API 응답(`api_error_status`·`result` 등)을 백엔드가 파싱해 **사람이 읽는 메시지로 분류 표출** (원문 JSON 노출 금지): ① **사용량 한도(429)** — 한도 종류(세션/일일/주간/특정 모델/전체)와 **리셋 시각** (예: "Claude 구독 세션 한도 초과 — 오늘 21:40 리셋 후 재시도"), ② 인증 만료/재로그인, ③ CLI 미설치/키 미등록, ④ 타임아웃, ⑤ 기타. 유형별 다음 행동 안내.
> 4. **한도 상태 기억**: 최근 429의 한도 종류·리셋 시각을 서버가 기억해 카드에 표시하고, 리셋 전 변환 시도 시 실행 전에 미리 경고 + 폴백 정책 적용(불필요한 실패 호출 방지).
>
> **F35 기출 소스 커넥터** (v1.x 후보 — 2026-07-24 사용자 제안: 문제은행 사이트에서 긁어와 LLM 후처리로 자격증 대분류·회차까지 자동 반입):
> - 기존 파이프라인 재사용이 원칙 — 신규는 **수집기(fetcher)** 뿐: 수집 → convert 잡 큐(LLM 정리) → 미리보기·중복 감지 → 분류 제안(회차 트리 자동 생성) → 승인 반입. F30(오류 신고)·F34(엔진 한도)와 연동.
> - **1단계 (URL 반입)**: 공개 기출 PDF/페이지 URL 입력 → 서버가 다운로드 → convert 투입. 어댑터 불요, 공단 공개 자료(큐넷 등) 우선 경로.
> - **2단계 (사이트 어댑터, M10 — 설계 §4.13. M13에서 큐넷 단일 경로로 축소)**: 자격증·회차 선택 UI → 수집 → 문제/보기/정답/해설 구조 추출 → "정보처리기사/실기/2023년 2회" 형태 분류 자동 생성. 그림 문제는 이미지를 sources/에 저장해 본문 삽입. 어댑터는 소스별 모듈로 분리(외부 구조 변경 시 해당 모듈만 수정 — R14).
>   - **대상 = 큐넷(Q-Net) 공식 오픈API 단일 경로 (2026-07-27 사용자 확정)**: 사이트 어댑터는 **공단이 공식 제공하는 오픈API(3단계)만** 사용한다. 사설 문제은행 어댑터(**전자문제집 CBT(comcbt.com)** — M10, **CBT문제은행(cbtbank.kr)** — M12)는 **M13에서 전면 제거**한다. 어댑터 2호 이상은 **공식 오픈API를 제공하는 기관에 한해** 실수요 확인 후 검토(사설 사이트 대상 어댑터는 재도입 대상이 아니다).
>   - **[제거 이력] 사설 사이트 어댑터 제거 — comcbt·cbtbank (2026-07-27 사용자 확정, M13 범위. 되살리려 하지 말 것)**
>     - *무엇이 있었나*: M10에서 comcbt(회차 PDF 첨부 → FetchedFile), M12에서 cbtbank(회차 페이지 정적 HTML → FetchedExam 구조 추출)를 붙였고, 중복 회차 우선순위(큐넷 > cbtbank > comcbt)·시험 날짜 자연 키 병합·`refs`/`also_on` 대안 어댑터 재시도·어댑터별 robots/스로틀 분기가 그 위에 얹혀 있었다.
>     - *왜 없앴나*: ① **배포 형태가 바뀌었다** — 앱이 **GitHub 공개 저장소 + 테스터 배포 체계**로 전환(2026-07-27 포터블 패키지 도입)되면서 "개인 PC 단독 사용 = 사적 이용"이라는 M10 당시 전제가 성립하지 않는다. 사설 사이트의 DOM을 겨냥한 수집 코드를 공개 배포하는 것은 리스크의 성격 자체가 다르다. ② **큐넷 오픈API는 공단이 공식 제공하는 수단**이라 이 문제가 없다(허용된 계약 위에서 동작). ③ 어댑터 다중화가 만들던 복잡도(우선순위 병합·중복 회차 날짜 키 병합·level_hint 오병합 방지·어댑터별 예의 규칙 분기)가 대부분 소멸한다 — 신규 구현(qnet)과 제거를 같은 단계(M13)에서 하면 병합 로직을 **단순한 형태로 새로 짤 수 있다**.
>     - *수용한 트레이드오프(기대치 명문화)*: **기사급 필기 CBT 기출(2022년 3회~)의 자동 수집 경로가 사라진다.** 큐넷 공개문제에는 필기 기출이 없다(공단 비공개 방침). 앞으로 **필기 기출은 F35-1 URL 반입 / 파일 반입(수동)** 경로로만 처리한다 — 사용자가 명시적으로 검토·수용한 결과다(2026-07-27). **학습 루프(퀴즈·오답노트·SM-2·복습)와 이미 반입된 문서는 영향 없다.**
>     - *유지되는 것(제거 대상 아님)*: **F35-1 URL 반입 · 파일 업로드 반입 · convert 파이프라인** — 특정 사이트를 겨냥한 코드가 아니라 사용자가 가진 자료를 넣는 **중립적 통로**다. 어댑터 인터페이스(`base.py`)·registry·수집 파이프라인(FetchedFile/FetchedExam 두 경로)·SSRF/스로틀/매직 바이트 등 안전 장치도 그대로 둔다(qnet이 사용).
>     - *데이터 처리 방침*: **이미 반입된 문서·`sources/` 원본·수집 이미지는 전량 보존.** 어댑터를 지운다고 과거 수집물을 지우지 않는다 — 소프트 삭제 원칙(불변 규칙 3)·`sources/` 불변(규칙 4) 그대로. `sources.note`에 남은 `comcbt · …`/`cbtbank · …` 출처 문자열도 **역사적 기록으로 보존**(정리·마이그레이션 없음 — DDL 0건).
>     - *기각한 대안(재제안 금지 — 기록만)*: "대상 사이트를 코드에서 감춰 저격 여부를 알 수 없게 하기". **은닉은 침해 판단에 영향이 없고 오히려 고의성 정황으로 작용**하므로 채택하지 않는다.
>   - **회차 동일성·대표 키(M13 단순화)**: 어댑터가 하나뿐이므로 **어댑터 간 병합·우선순위 채택은 존재하지 않는다**(`also_on`은 항상 빈 배열, `refs`는 단일 항목). 남는 것은 **exam_key 형식과 폴더명 파생**뿐 — `YYYY-N` → "YYYY년 N회", 날짜형 `YYYY-MM-DD` → "YYYY년 M월 D일"(회차 번호를 알 수 없는 회차용 폴백). 문서 단위 중복은 기존 반입 중복 감지(§8.3) 재사용 — 별도 장치 없음. (M10~M12의 우선순위 병합·날짜 자연 키 병합 규칙은 제거된 다중 어댑터 전제에서만 의미가 있었다.)
>   - **스키마 변경 불필요 근거(2026-07-25 확정 · M12 재검증 2026-07-26 · M13 재확인 2026-07-27)**: 회차 메타는 기존 구조로 충분 — 회차 = `categories` 노드(분류 자동 생성 재사용), 문항 위치 = `documents.source_detail`("YYYY년 N회 M번"), 수집 출처 = `sources.note`(URL·어댑터 id). "이미 반입된 회차" 표시는 분류 경로 존재 여부에서 파생. 새 테이블·컬럼 없음. 어댑터 자료구조의 추가 정보(회차 시험 날짜·문항 과목 구분)는 **파이썬 dataclass·프롬프트 계층에서만 흐른다** — DB에는 기존 경로(분류 경로·source_detail·태그 제안)로만 반영, DDL 0건. **어댑터 제거도 DDL·마이그레이션 0건**(어댑터 id는 DB 스키마가 아니라 `sources.note` 자유 텍스트에만 등장).
> - **3단계 (큐넷 공식 오픈API, **M14 — 후순위**. 2026-07-27 스펙 확보 후 같은 날 실호출 실측으로 범위·한계 확정. **M13 이후 유일한 사이트 어댑터**)**: S10에서 유예된 qnet 목록 스텁(`available:false` — JS 포털 역설계 불가, R14 실측 사례)을 공공데이터포털 공식 오픈API **"국가자격 공개문제 조회 서비스"**(`apis.data.go.kr/B490007/openQst` — REST GET, `serviceKey` 쿼리 인증, XML/JSON)로 해소한다. 역설계·스크랩이 아닌 **공식 계약** — robots·DOM 파손 리스크 자체가 소멸하고, 어댑터 격리(R14) 덕에 **qnet.py만 수정, fetch API 계약 불변**(사설 어댑터 제거 후에도 `adapters`/`certs`/`exams`/`import` 계약 형태는 유지 — 설계 §4.13).
>   - **[실측 확정 사항 — 2026-07-27, 실제 호출로 확인. 구현은 이 값을 전제로 한다]** 서비스키로 `getOpenQstList`(`qualgbCd=T`) 전수 수집 **304건** + 상세 12건 무작위 샘플(`resultCode 00 NORMAL SERVICE`):
>     1. **`numOfRows` 최대 50**(스펙 문서에 없던 제약) — 51 이상은 `resultCode 930`. 전체 순회 **7페이지**. 페이지네이션 필수, 페이지 크기 50 고정.
>     2. **계열 분포**: 기능사 151 · 기사/산업기사 87 · **메타 빈값 43** · 기능장 18 · 변리사 2 · 공인노무사 2 · 주택관리사보 1.
>     3. **메타데이터 누락 43건(14%)** — `qualgbCd/qualgbNm/seriesCd/seriesNm/jmCd/jmNm`이 **전부 빈 문자열**인 게시물 존재(artlSeq·title·일시는 정상). **종목 기준 그룹핑·필터가 깨진다 → 방어 처리 필수**(빈 값으로 가짜 종목을 만들지 않고, 제목 검색으로는 노출).

>     6. **제목 형식 불규칙**: `[공개문제]봉제기능사(20260714)` · `[공개문제]양식조리산업기사(2026년도)` · `[문제공개]와전류비파괴검사기사` · `[공개문제] 2025년 미용사(일반) 실기시험관련 안내` · `미용사(일반)과제 조별 집행 안내` — 접두어·공백·회차 표기가 제각각이고 **공개문제가 아닌 안내문 게시물이 섞여 있다**(기본 숨김 + 토글 노출, 판정은 제목 텍스트만 — 상세 조회는 쿼터 소모).
>   - **[구현 확정 사항 — 2026-07-27, M14 완료 시점. 위 실측값의 재확인 + 구현에서 굳은 계약]**
