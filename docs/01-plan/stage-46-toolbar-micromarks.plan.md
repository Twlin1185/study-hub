## 2. 확정 규약 (착수 전 결정 — 위임 판정, 이 문서가 정본)

- **A. 상호 배타 규약 C 불변 — Ctrl+U는 반드시 래퍼 경유**: 밑줄 토글의 유일 경로 =
  `toggleMicroMark(editor,'underline')`(`microMarks.ts` — 강제 지점 ①). 코어
  `toggleStyles({underline:true})` 직행 경로를 만들지 않는다. **Ctrl+U 가로채기 래퍼는 기존재** —
  `useMicroMarkShortcuts`(document 캡처 등록·PM보다 선행·`NoteEditorDialectUI.tsx:56` 장착 = 노트·문서
  양 표면 공용)가 이미 Mod+U를 `toggleMicroMark`로 돌린다. 따라서 FB-17의 "안 먹힘"은 ⓐ 실측으로
  동작 여부부터 판정하고(부유·도킹, 노트·문서 양 표면) ⓑ 실제 미동작 표면 발견 시 원인 수정(래퍼 경유
  불변) ⓒ 동작하는데 안 보였던 것이면 FB-16 수정으로 해소 — 판정 결과를 §8에 명기한다.
  **형광·스포일러 신규 단축키 금지**(screens §5.16 확정 — "가로채는 단축키는 기존 Mod+U 하나뿐").
- **B. 아이콘 = 밑줄·글자 크기 2개만 + 신규 의존 0**: `react-icons`는 **잠금 파일에 부재**(실측
  2026-09-02 — BlockNote 0.54는 `@blocknote/react` 의존에서 아이콘 라이브러리를 쓰지 않고 자체 SVG
  번들) → 도입하면 신규 의존이 된다(D10 심사 대상·금지 아님이나 불필요). **자체 인라인 SVG**(또는 CSS
  글리프)로 구현 — 기본 버튼(스트로크 계열)과 시각 결이 맞게. `label`·`mainTooltip` 한글 텍스트는
  유지(접근성·발견성). **전면 아이콘화 금지** — 나머지 버튼(코드·형광펜·스포일러·글자색·바탕색·참조
  등)은 텍스트 라벨 현행 유지. 색은 `currentColor`/토큰만(불변 규칙 5 — SVG에 색 리터럴 0).
- **C. 순서 변경 = 빌더 한 곳에서만**(stage-40 규약 A ③ — 부유·도킹 동시 반영): 기본 항목의 상대
  순서는 계속 불변(stage-40 관례). ⓐ **밑줄 아이콘 버튼 = 제거된 기본 밑줄 자리에 삽입**
  (`defaultToolbarItems`가 `DEFAULT_UNDERLINE_ITEM_KEY`를 걸러내는 지점에서 치환 — bold·italic 옆,
  사용자 기대 위치) ⓑ **글자 크기(아이콘) = 방언군 선두로 전진**. 구현 제약(키 충돌·가드 덮개 간섭 등)
  발견 시 밑줄도 방언군 선두 배치로 대체 가능하되 §8에 사유 보고. 원자 가드(`blocked`)·텍스트
  서식군 필터(`group:'text'`) 소속은 현행 그대로 승계.
- **D. FB-16 해법 방향 — 대기 마크를 active 판정에 병합**: 접힌 커서에서 버튼/단축키로 걸린 **대기
  마크(ProseMirror storedMarks 계열)** 가 active 표시에 반영되게 한다. `useActiveStyles()` 소비 지점
  5곳(`MicroMarkButton`·`InlineCodeButton`·`HighlightMenu`·`ColorMenu`·`SizeMenu`)이 **공용 헬퍼
  1곳**을 거치게 구성(중복 5벌 금지). 원인 확정(어느 계층이 대기 마크를 떨구는지)과 구체 구현은
  구현 조사에 위임 — 단, `microMarks.ts`의 토글 판정(`getActiveStyles`)과 표시 판정이 어긋나 이중
  토글이 나지 않는지 함께 검증.
- **E. FB-19 해법 — 후보 (a) 우선, 최종 선택은 구현 조사**: **(a) 스포일러를 비-React
  `createStyleSpec`(vanilla)으로 전환**(권고 1순위) — DOM 동기 생성으로 React 포털 커밋↔PM DOM 패치
  어긋남(추정 원인 — `specs/styles.tsx` `SpoilerStyleRender`의 `createReactStyleSpec`+`useState`
  노드뷰) 자체를 제거. 공개/비공개 토글은 click 리스너 + data-attribute 토글 + CSS(Tailwind
  data-variant 또는 `notes.css`+tokens)로 대체(`useState` 제거). 렌더 클래스·토큰 경로는 현행
  유지(색 리터럴 0 — `bg-primary`/`bg-bg` 먹칠 관례·`print:` 항상 공개 그대로). **(b)** 조사가 더
  나은 접근을 확증하면 대체 가능. **불변 계약**: 저장 포맷 `spoiler: true`(boolean 스타일) · 방언
  왕복 `||…||` · 인쇄 항상 공개 · 리더(`MarkdownView`의 `InlineSpoiler`) 무접촉 · `schema.ts`
  styleSpecs 등재 키(`spoiler`) 무변. **형광펜(`highlightStyleSpec`)·`:t`(`textStyleSpec`)도 V-3
  동일 절차에서 결함이 실측되면 같은 방식으로 전환**(미재현이면 무접촉 — 예방 전환 금지·YAGNI).
- **F. 공통 한도**: 신규 의존 0(D10 — GPL 금지·저장소 public) · 색상 토큰만(불변 규칙 5) ·
