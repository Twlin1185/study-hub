# Stage 11 — 시험 직전 도구 (M11: 실전 모의고사 · D-Day 복습 강도 조절)

> 상위: `study-app.plan.md` v0.12 §14(M11), F25·F16 명세 · 설계: `../02-design/study-app.design.md` v1.10 **§4.14** + §5(5.6·5.7·5.11·**5.12**)
> 선행: Stage 10 완료(M10 — 틀린이유 원탭(F36-⑤)·설정 6그룹·srs/summary 사용 가능) · 포함: **F25**(실전 모의고사 — 일괄 제출 채점·과목별 리포트), **F16**(D-Day 복습 강도 조절 — SRS 큐 부스트)
> **스키마(§6.2 DDL) 변경 없음 — Alembic 마이그레이션 0건.** 근거는 계획서 §14 F25·F16 명세(리포트·이력 = attempts 파생(런 키 = 배치 공통 answered_at), 강도 조절 = settings 키 1개 + 전부 파생 — 큐 구성 계층만).
> 불변 규칙 재확인: `exam/session` 응답에 정답·해설 절대 금지(규칙 1) · 일괄 제출은 **배치 전체가 한 트랜잭션**(규칙 2) · `services/sm2.py` 알고리즘·`srs_cards` 저장값(EF·interval·due_date) 수정 금지(F16은 큐 구성 계층만).

## 목표

시험 노드를 고르면 **실제 시험 형식(과목 구성·제한 시간·일괄 채점)으로 모의 응시**하고, 과목별 점수·과락·합격이 리포트로 보인다(틀린 문제는 오답노트·SM-2에 자동 합류).
시험이 **14일 이내로 임박하면 복습 큐가 저절로 강해진다** — 상한 확대·임박 범위 우선·선행 복습, 시험이 지나면 저절로 원복.

## 작업 체크리스트

### 1. 백엔드 — 채점 코어 분리 + 모의고사 API (F25, 설계 §4.14)
- [x] **채점 코어 분리**: `attempt_service`의 단건 채점(정규화 비교 · avg_time/직전오답 q 매핑 · 오답노트 생성/재사용 · study_progress · SM-2)을 **커밋 없는 공용 함수**로 추출 — 단건(quiz)·배치(exam)가 같은 규칙 공유(srs_service.apply_sm2 전례). 기존 `POST /api/attempts` 동작·응답 **완전 불변**
- [x] `services/exam_service.py` + `routers/exam.py` — `POST /api/exam/session`: subjects별 출제(quiz_service 자격 판정·서브트리 deep·types 필터 재사용, random/sequential, count 절단(미지정=전체·과목당 상한 200), 0문항 과목 제외+`warnings`, 전 과목 0이면 422). `time_limit_minutes` 미지정 시 `ceil(총 문항×1.5분)` 에코. **응답에 정답·해설 없음**(불변 규칙 1 — QuizQuestionOut 재사용). 서버 세션 저장 없음(무상태)
- [x] `POST /api/exam/submit` — 전 문항 채점(코어 재사용) + attempts INSERT(mode=`'exam'`, category_id=과목 노드, **배치 공통 answered_at** — 런 키) + 오답노트 + SM-2 + 진도 = **배치 전체 한 트랜잭션**(중간 실패 시 전무 롤백). 미응답(null)=오답. `subject_category_id` 소속 검증(문서가 그 과목 서브트리에 연결 — 아니면 422). 리포트 응답: 과목 점수 `round(100×정답/문항)` · 과락(`< subject_min` 기본 40) · 총점 = 과목 **단순 평균** · 합격(비과락 AND ≥ `pass_avg` 기본 60) + `results` 문항별(정답·해설 공개 — 제출 후) + `review_note_id`
- [x] `GET /api/exam/history?limit=20` — attempts(mode='exam') answered_at 그룹 **파생**(저장 없음), 시험 라벨 = 과목 노드 공통 부모 경로(삭제된 분류는 "(삭제된 분류)"), 합격 재평가 = 기본 컷 40/60 고정(R15). 배열 반환(limit 절단 — srs/today 전례)

- [x] `models.py` attempts.mode 주석에 `'exam'` 반영(§6.2 주석 정합 — 값 제약·마이그레이션 없음)

### 2. 백엔드 — D-Day 복습 강도 조절 (F16, 설계 §4.14)
- [x] **발동 판정 + 유효 상한 함수**: `srs.dday_boost`(settings DEFAULTS에 `'on'` 추가) AND `categories.exam_date` 중 0≤d_day≤14(지난 날짜·임의 D-Day 제외). 유효 상한 = D≤7 `ceil(limit×2)` / D8~14 `ceil(×1.5)`(배율은 최소 d_day 기준) — **get_today_queue · 개수 산출(dashboard today_review) · srs/summary가 같은 함수 공유**
- [x] 큐 우선순위 확장: 미해결 오답노트(기존 1순위 유지) > **임박 시험 서브트리 소속**(여러 시험이면 합집합) > due 오래된 순 + **선행 복습**(D≤7만): due 미도래 카드를 남는 자리에 due 오름차순으로 채움 — item `ahead:true`. **개수 산출과 큐 길이 일치**(min(due,limit) 단순식 금지 — 선행 포함)
- [x] `srs/summary` 확장: 발동 시에만 `dday_boost {category_id, name, exam_date, d_day, multiplier, effective_limit}` (미발동 시 필드 생략 — 하위 호환, S10 goal_met 전례). `srs/today` item에 `ahead`(기본 false)
- [x] 유효 상한·발동 판정 **단위 테스트**(경계 D0/D7/D8/D14/D15 · 토글 off · 임의 D-Day 무시 · 지난 시험 무시)

## 완료 기준 (DoD)

1. 시험 노드 선택 → 과목 체크 → 응시 → 일괄 제출 → 리포트가 끊김 없이 완결. **응시 중 네트워크 응답 어디에도 정답·해설이 없음**(개발자 도구로 exam/session 응답 확인)
2. 제출 후 오답(미응답 포함)이 오답노트에 자동 수집되고 SRS due가 갱신됨 — 배치가 **한 트랜잭션**(제출 중 강제 오류 주입 시 attempts 0건)
3. 타이머 0초 → 자동 제출, 미응답은 오답으로 리포트에 반영
4. 과락 1과목(40점 미만)이면 평균 60 이상이어도 **불합격** 표기. 컷을 바꿔 응시하면 판정에 반영
5. 회차 노드 1개 선택 시 전체 문항·순차의 "회차 그대로" 모의가 동작
6. `exam/history`에 방금 응시가 즉시 나타남 — 새 테이블 없이(attempts 파생 확인)
7. `exam_date`를 D-7로 설정하면 복습 큐 상한 ×2·임박 범위 우선·선행 복습(ahead 배지)이 동작하고 복습 헤더에 강화 배지 표시. **D-15면 기존과 완전 동일**, 토글 off면 전부 기존과 동일
8. 홈 `today_review` 수치 = `srs/today` 큐 길이 = `srs/summary.today_due` (부스트 발동 시에도 일치)
9. sm2.py diff 0 · `srs_cards` 저장값(EF·interval·due_date)을 큐 조절이 변경하지 않음(선행 복습 카드도 풀기 전까지 불변)
10. §6.2 DDL diff 0 · Alembic 마이그레이션 0건. 기존 quiz/session·attempts·srs/today·srs/summary의 **기존 호출부 응답 불변**(추가 필드는 optional/생략형만)

## 이 단계에서 하지 않는 것

**exam_runs 등 리포트 저장 테이블**(파생으로 충분 — 실수요 확인 시 R15 절차로 재검토), 응시 당시 컷·제한시간 보존과 상세 리포트 재열람(이력은 요약 재평가만),
**서버 측 타이머 검증·세션 저장**(개인용 로컬 — 무상태 유지), 시험별 합격선 프리셋·컷 settings 저장(요청 파라미터로 충분),
모의고사 점수 추이 차트·대시보드 위젯(v1.x 후보 기록만), 재응시 동일 세트(셔플 시드 저장) · CBT 실제 화면 모사, 실기(서술형) 모의고사(R11 보류와 동일),
F16: **sm2.py·srs_cards 저장값 조작**(금지 — 큐 구성 계층만), 임의 D-Day 기반 강도 조절(분류 범위 없음), 임계(14일)·배율(×1.5/×2)의 사용자 설정화(상수 — 토글 on/off만),
과목별 차등 강도·시험별 개별 상한, 목표 미달·D-Day 알림/푸시.
