### B. 최악 시 강등 경로 — 판정 기준·절차 (마스터 §14 M36 행 "보기 전용+간이 입력"의 구체화)

  (수정 또는 후속 경로).

  경로 — 이미 완전한 편집 경로)**로 자동 분기(분기 1곳·신규 표면 0). 마스터 행의 "보기 전용+간이
  입력"은 이 경로의 상위 호환이 이미 존재하므로 **신규 간이 입력 표면을 만들지 않는 것으로 구체화**한다

  표면이 없고, 간이 입력 신규 표면은 그보다 기능이 적으면서 비용만 든다).
- **강등 2단(사실상 미도달) = 보기 전용**: 1단마저 불능일 때만 — 별도 계획서 선행(임의 착수 금지).
