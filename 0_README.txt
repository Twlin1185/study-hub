================================================
 Study Hub - 처음 시작하는 분을 위한 안내
================================================

Python, Node 같은 프로그램이 하나도 설치되지 않은
Windows PC에서 Study Hub를 실행하는 방법입니다.


[필요한 것]

 - Windows 10 또는 11 (64비트)
 - 인터넷 연결: 맨 처음 1회만 필요합니다.
   (필요한 파일 약 100MB를 자동으로 내려받습니다)
 - 따로 설치할 프로그램: 없음


[실행 방법]

 1. 이 폴더를 통째로 받습니다.
    - zip으로 받았다면 압축을 풀어 바탕화면 등 일반 폴더에 두세요.
    - OneDrive 동기화 폴더나 Program Files 폴더는 피하세요.

 2. "2_StartServer.bat" 를 더블클릭합니다.   <-- 이것 하나면 됩니다
    - 처음이면 초기 설정이 자동으로 먼저 실행됩니다 (몇 분 걸림).
    - 끝나면 서버가 켜지고 브라우저가 자동으로 열립니다.
    - 주소: http://localhost:8000

 3. 끝낼 때는 검은 창을 닫으면 됩니다.
    서버가 안 꺼지고 남아 있으면 "3_StopServer.bat" 를 실행하세요.


[파일 설명]

 0_README.txt          지금 보고 있는 안내문
 1_Setup.bat           초기 설정 (2번이 알아서 실행하므로 직접 누를 필요 없음)
 2_StartServer.bat     서버 시작   <-- 평소에 쓰는 것
 3_StopServer.bat      서버 강제 종료 (비상용)
 Dev_StartServer.bat   개발자 PC 전용 (실수로 눌러도 자동으로 2번으로 넘어감)


[문제가 생기면]

 - 파란 창 "Windows에서 PC를 보호했습니다" 가 뜸
   -> "추가 정보"를 누른 뒤 "실행"을 누르세요.

 - 방화벽 허용 창이 뜸
   -> 휴대폰(같은 와이파이)에서도 접속하려면 "허용".
      PC에서만 쓸 거면 아무거나 눌러도 됩니다.

 - 다운로드 실패라고 나옴
   -> 인터넷 연결을 확인한 뒤 2_StartServer.bat 를 다시 실행하세요.
      (이미 받은 부분은 건너뛰고 이어서 진행됩니다)

 - 설치가 꼬인 것 같음
   -> python-embed 폴더를 통째로 삭제한 뒤 2_StartServer.bat 를 다시 실행하세요.

 - 브라우저가 저절로 안 열림
   -> 브라우저를 열고 주소창에 직접 입력: http://localhost:8000


[알아두면 좋은 것]

 - 처음에는 빈 상태로 시작합니다.
   학습자료는 앱 안의 가져오기 기능으로 넣습니다.
 - LLM 자동 구조화 기능만 API 키가 필요합니다 (앱의 설정 화면에서 등록).
   키가 없어도 학습, 퀴즈, 오답노트, 복습 기능은 전부 사용할 수 있습니다.
 - 사용 설명서: 서버 실행 후 http://localhost:8000/manual
 - 데이터는 study.db 파일 하나에 저장됩니다. 백업 = 이 파일 복사.
 - 이 앱은 집 안(홈 네트워크) 전용입니다. 외부 인터넷에 포트를 열지 마세요.
