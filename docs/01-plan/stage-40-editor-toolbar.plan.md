## 확정 규약 (①~③ 위임 판정으로 유효 — 이 문서 + screens §5.16 S40 추기가 정본)

### A. 도킹 서식 툴바 (FB-9)

- ① **위치·형태**: `BlockNoteView`의 **children 안**(`useComponentsContext`·`useBlockNoteEditor` 컨텍스트가
  거기서만 유효 — 실측: `NoteEditorDialectUI.tsx` 42행 `FormattingToolbarController` 한 줄이 부유 툴바의
  전부) · 시각적으로 **편집 표면 최상단·sticky**(스크롤해도 표면 상단에 붙는다. 상단 [저장]/[취소] 헤더가
  sticky라면 그 아래에 겹치지 않게 offset — DOM 순서상 children이 편집 DOM 뒤에 오므로 상단 배치·sticky
  offset 방식은 **구현 재량**(CSS `order`/flex 등). 계약 = "겹침 없이 상단·상시 표시").
- ② **표면당 1개**: `BlockNoteView`는 노트(`NoteEditPage.tsx`)와 문서 표면(`documents/BlockSurface.tsx` —
  본문·해설 등 **표면당 1개**)에서 열린다 → **도킹 툴바도 표면마다 1개**. 판정 기준 = **그 표면 편집기의 현재
  선택/커서**(포커스가 빠져도 편집기 선택 상태는 남는다 — "활성 표면에만 표시"는 하지 않는다: 레이아웃 점프
  방지). 비포커스 표면의 버튼 클릭 = 해당 편집기에 포커스 복귀 후 적용(구현 재량 — 선택이 없으면 무동작).
- ③ **항목 구성 단일 출처**: 부유(`NoteFormattingToolbar.tsx` 469~488행 — `defaultToolbarItems(blocked)` +
  방언 버튼 8종)와 도킹은 **같은 항목 빌더 1개**를 공유한다(항목 목록·순서·원자 가드 `blocked`·규약 B 필터
  전부 동일). 도킹 전용 항목·부유 전용 항목 **0**(이중 조작 혼동 방지 — 결정 ①의 근거). 구현은 빌더 함수
  분리 + `<FormattingToolbar>` 컴포넌트를 컨트롤러 밖 고정 컨테이너에 렌더(별지 §13 FB-9 기술 전망).
- ④ **포커스·선택 보존**: 도킹 툴바 클릭이 편집기 선택을 잃게 해서는 안 된다(`mousedown preventDefault`
  관례 — 부유 툴바는 포털이 알아서 하지만 도킹은 직접 해야 한다). 드롭다운(형광·색·크기·콜아웃)은
  부유와 같은 `Components.Generic.Menu` 사용.
- ⑤ **모바일(<768px)**: 도킹 툴바는 **1줄 가로 스크롤**(`overflow-x: auto` — 상시 점유 높이 최소화. stage-38
  "부유 툴바 3줄 118px 유지" 결정은 **부유에만** 유효·무변 — 도킹이 3줄을 상시 점유하면 폰 편집 영역을
  잠식한다). 버튼 최소 높이 36px(stage-38 D7 수준 유지). 도킹 툴바 전용 클래스(예 `editor2-docked-toolbar`)로
  기존 `.bn-mantine .bn-toolbar` 모바일 규칙(notes.css 265~285행)과 **분리**해 부유 규칙 무변을 보장.
- ⑥ **가상 키보드**: 상단 배치라 키보드와 직접 겹치지 않는다 — 단 iOS 뷰포트 축소 시 sticky 상단이 화면 밖으로
  밀리는지는 **실기기 DoD 항목**(결정 ② 재론 트리거).
- ⑦ 색·상태 전부 토큰(불변 규칙 5 — 신규 색 0). 도킹 on/off **설정 토글 없음**(settings 키 0 — 항상 표시).

### B. 블록 타입별 툴바 필터 (FB-6) — 부유·도킹 공통 규칙

- ① **판정 입력** = 선택 범위에 걸친 **블록 집합**(범위 선택이면 그 블록들 · 커서만 있으면 커서 블록 1개 —
  도킹 툴바의 "선택 없음" 상태도 이 규칙 하나로 판정). 순수 함수 1개(예 `toolbar/blockFilter.ts` —
  입력 = 블록 타입 문자열 배열, 출력 = 군별 표시 여부)로 두고 **부유·도킹이 같은 함수**를 호출한다.
- ② **군 정의**(실측 스키마 `blocknote/schema.ts` 125~145행 기준):
  - **원자·미디어 블록** = `image` · `webEmbed` · `docEmbed` · `toc` · `divider` · `mathBlock` · `sourceFallback`
    (읽기 전용 보존 블록 — 서식 대상 아님).
  - **코드 블록** = `codeBlock`(코드 안 인라인 서식은 Markdown 펜스에 실리지 않아 **저장 왕복 불가**).
  - **텍스트 블록** = 그 외(`paragraph`·`heading`·목록 3종·`quote`·`table`·`callout`).
  - **텍스트 서식군**(툴바 항목) = 코어 bold/italic/strike/link + 방언 underline/highlight/spoiler/color(c·bg)/
    size + **인라인 코드(규약 C 신설)** + 참조 칩 삽입(`RefButton` — 인라인 삽입이라 텍스트 위치가 필요).
  - **블록 기능군** = 코어 블록 타입 변경·콜아웃 감싸기(`CalloutMenu`)·이미지 자르기(`CropButton` — 자체
    가드 유지)·코어 파일 블록 항목(이미지 캡션/교체 등 — 엔진 기본값 그대로) · (stage-41에서 다단 메뉴 가산).
- ③ **규칙**:
  1. 집합이 **전부 원자·미디어 블록** → 텍스트 서식군 **숨김**(비활성 아님 — 사용자 표현 "불필요") · 블록
     기능군 유지.
  2. 집합이 **전부 코드 블록** → 텍스트 서식군 **숨김**(인라인 코드 버튼 포함) · 블록 기능군 유지.
  3. **혼합**(텍스트 블록 + 원자/코드 블록) → 텍스트 서식군 **표시**(텍스트 부분에는 적용 가능) · 원자 인라인
     가드(`toolbar/atoms.ts` — `blocked`)는 종전대로 별도 적용(블록 필터와 인라인 가드는 **직교** —
     둘 다 살아 있다).
  4. 집합이 **비어 있음**(편집기 미포커스·선택 정보 없음 — 도킹 툴바만 해당) → 텍스트 블록과 동일 취급
     (기본 전체 표시 — 숨겼다 나타나는 깜빡임 방지).
- ④ 부유 툴바는 엔진이 원자 블록 선택 시에도 띄우는 경우(이미지 블록 선택 등)에 한해 같은 규칙으로 항목이
  줄어든다 — **부유 툴바 표시 여부 자체(엔진 판단)는 건드리지 않는다**(R33 엔진 내부 비접촉).
- ⑤ 숨김은 **렌더 생략**(DOM 없음)이며 툴바 폭이 줄어 레이아웃이 흔들리는 것은 허용(도킹은 좌측 정렬 —
  남은 항목이 왼쪽에 모인다).

### C. 인라인 코드 툴바 버튼 (FB-11 ⓒ)

- 방언 버튼 전례(`MicroMarkButton` — 원자 가드 `blocked` 인자)를 따르되 **토글 대상은 코어 `code` 스타일**
  (`editor.toggleStyles({ code: true })` · 활성 판정 = `getActiveStyles().code`) — 신규 스타일 스펙 0·어댑터
  무변(실측: `adapter/fromBlockNote.ts` 193행 `inlineCode` 왕복 성립 · 백틱 입력 규칙 · 코어 `Ctrl+E` 단축키 +
  `useAtomMarkGuard` 가드 전부 기존재). 버튼은 **발견성 결함의 해소**일 뿐 새 기능이 아니다.
- 위치 = 텍스트 서식군(규약 B ②) · 라벨/툴팁 문구는 구현 재량(한글 라벨 관례 — "코드").
- 원자 인라인 포함 선택 → 가드(기존 `blocked` 규칙) · 코드 블록/원자 블록 선택 → 규칙 B로 숨김.

### D. 코드 블록·인라인 코드 외양 (FB-11 ⓐ) — 토큰 CSS만

- 대상 = 편집 표면의 `[data-content-type='codeBlock']`(실측: `notes.css`에 규칙 **0** — 엔진 기본 외양) +
  인라인 코드(`code` 스타일 span). **리더(`MarkdownView` — rehype-highlight 코드 블록)의 기존 외양은
  무접촉** — 편집 표면을 리더 외양에 **근접**시키는 것이 목표(같은 토큰 사용).
- 코드 블록: 배경(`--surface-raised` 계열)·테두리(`--border`)·둥근 모서리·모노 폰트·**상단 언어 라벨**
  (엔진 기존 언어 드롭다운의 자리를 우상단으로 정돈 — 드롭다운 자체는 엔진 것 그대로) · 다크 = 토큰으로
  공짜(불변 규칙 5 — 색 리터럴 0). **복사 버튼은 이 단계 제외**(코어 `codeBlock` 뷰 개조가 필요 — R33.
  실수요 시 후속).
- 인라인 코드 칩: 배경·테두리·모노 폰트·패딩(리더의 인라인 `code` 외양과 동일 토큰).
