# Stage 14 — 큐넷 공식 오픈API 연동 (M14: F35 3단계 실가동 — **후순위 편의 기능**)

> 상위: `study-app.plan.md` **v0.17** §14(M14), F35-3 명세 + **"실측 확정 사항(2026-07-27)"** · 설계: `../02-design/study-app.design.md` **v1.14** §4.13(S14 — qnet 오픈API)·§5.9(사이트 반입 스텝)·§5.11(데이터 그룹 서비스키 카드)
> 선행: **Stage 13 완료**(사설 어댑터 제거 → 등록 어댑터 = qnet 스텁 1개, 병합 로직 단일 어댑터화, F40 수동 반입 UX). 이 단계는 그 스텁을 공식 오픈API로 채우는 작업이다.
> **왜 후순위인가(2026-07-27 사용자 확정)**: 실호출 실측 결과 이 API는 **실기 작업형·도면 공개문제 카탈로그**이고, **사용자의 실제 학습 대상인 필기·필답형 종목은 구조적으로 범위 밖**이다(품질경영기사 `jmNm` 검색 = `totalCount 0`, 기사 계열 87건에도 없음). 학습 기여도가 확인되지 않은 편의 기능이므로 수동 반입 UX(M13/F40) 뒤로 미룬다. **연동 자체는 여전히 가치가 있다** — 실기 공개문제·도면은 공식 경로로만 얻을 수 있고, 역설계 없는 공식 계약이라 R14 리스크가 없다.
> 성격: **역설계·스크랩이 아닌 공식 계약**(공공데이터포털 "국가자격 공개문제 조회 서비스" `apis.data.go.kr/B490007/openQst`) — S10 "qnet JS 포털 역설계 불가" 유예(R14 실측 사례)의 번복이 아니라 해소.
> **스키마(§6.2 DDL) 변경 없음 — Alembic 마이그레이션 0건**: 서비스키 = 루트 `secrets.json`(F34 전례 — DB/settings 금지), 목록 = 기존 메모리 캐시(24h), 출처 = `sources.note`(artlSeq·API URL), 회차·경로·imported = 기존 categories·source_detail 파생.
> 불변 규칙 재확인: **서비스키 write-only**(응답·로그에 원문 금지 — 요청 URL 로깅 시 serviceKey 마스킹) · **`fileUrl` JWT 유효 1시간(에러 941) → 상세 조회와 첨부 다운로드는 같은 잡에서 즉시 연속 수행**(목록·캐시에 fileUrl 저장 금지) · `sources/` 원본 불변 · 개인 학습 전용·재배포 금지 고지 · 실행 전 예상 LLM 사용량 안내 · 도메인 2초 스로틀·50MB 상한·SSRF 검증 기존 장치 유지.

## 실측 확정 사항 (2026-07-27 — 실제 호출로 확인. 추측 아님, 구현은 이 값을 전제로 한다)

서비스키로 `getOpenQstList`(`qualgbCd=T`) 전수 수집 **304건** + 상세 12건 무작위 샘플링. `resultCode 00 NORMAL SERVICE`.

1. **`numOfRows` 최대 50** — 공식 스펙 문서에 없던 제약이다. 51 이상이면 `resultCode 930`("한 페이지당 조회 가능한 최대 목록 수는 50개를 넘을 수 없습니다"). **전체 순회에 7페이지** — 페이지네이션은 선택이 아니라 필수이고, `numOfRows`는 50으로 고정한다.
2. **계열 분포(304건)**: 기능사 151 · 기사/산업기사 87 · **메타데이터 빈값 43** · 기능장 18 · 변리사 2 · 공인노무사 2 · 주택관리사보 1.
3. **메타데이터 누락 43건(14%)** — `qualgbCd`·`qualgbNm`·`seriesCd`·`seriesNm`·`jmCd`·`jmNm`이 **전부 빈 문자열**인 게시물이 존재한다(artlSeq·title·일시는 정상). **종목(jmCd) 기준 그룹핑·필터가 이 항목에서 깨진다** — 방어 처리 필수.
4. **첨부 포맷(샘플 12건, 첨부 18개)**: **PDF 14 · ZIP 4 · HWP 0.** 예상과 달리 실제 비대응 포맷은 HWP가 아니라 **ZIP(도면·과제 묶음)** 이다. 한 게시물이 pdf+zip을 동시에 가진 사례도 있다(양식조리산업기사).
5. **커버리지 한계(가장 중요)**: `jmNm=품질경영기사` → **`totalCount 0`**. 이 API의 수록 대상은 **실기 작업형·도면 공개문제**이며, 필답형 실기·필기는 공개 대상이 아니다 — **필기·필답형 종목은 구조적으로 범위 밖**이다.
6. **제목 형식 불규칙(실측 표본)**: `[공개문제]봉제기능사(20260714)` · `[공개문제]양식조리산업기사(2026년도)` · `[문제공개]와전류비파괴검사기사` · `[공개문제] 2025년 미용사(일반) 실기시험관련 안내` · `미용사(일반)과제 조별 집행 안내` — 접두어(`[공개문제]`/`[문제공개]`/없음)·공백·회차 표기(`YYYYMMDD` / `YYYY년도` / 없음)가 제각각이고, **공개문제가 아닌 안내문 게시물이 섞여 있다.**

## 목표

공공데이터포털 서비스키를 설정에서 한 번 등록하면, 자격증 검색 → 회차(게시물) 목록에 **큐넷 공개문제가 나타나고**, 반입 실행 시 **첨부 PDF가 FetchedFile 경로로 convert→미리보기까지 완결**된다.
PDF가 없는 게시물(ZIP·HWP 등)도 **원본은 확보되고 다음 행동이 안내**된다(조용한 스킵 없음). **필기·필답형은 이 경로로 오지 않는다**는 사실이 화면·매뉴얼에 명시돼 기대치가 어긋나지 않는다.

2. **키 등록**: 잘못된 키는 즉석 검증 실패 사유가 표시되고 저장되지 않는다. 올바른 키는 suffix만 표시되고 `secrets.json`에만 존재(DB·settings·백업 스냅샷에 0건) — 서버 로그 전수에서 원문 키 0건
3. **전수 목록**: 캐시 미보유 상태에서 목록 수집이 `numOfRows=50` × 7페이지 내외로 완료되고 **930 에러가 0건**이며, 수집 건수가 실측치(약 304건, 데이터 갱신에 따라 증감)와 같은 자릿수다
4. **메타 빈값 방어**: 빈 `jmCd/jmNm` 항목이 종목 목록에 가짜 종목을 만들지 않고, 제목 검색으로는 노출된다 — 43건이 조용히 사라지지도, 목록을 오염시키지도 않는다
5. **제목 파싱**: 실측 6의 5개 표본이 테스트로 고정되고, 회차를 지어내는 사례가 0건(식별 불가 = 단독 항목). 안내문 게시물은 기본 목록에서 빠지고 토글로 볼 수 있다
6. **반입**: 실기 공개문제 1건이 상세 조회→첨부 다운로드→convert→미리보기까지 완결되고, 잡 로그에서 상세와 다운로드가 **같은 잡 내 연속 수행**(1시간 토큰 내)임이 확인된다
7. **ZIP 전용 게시물**: 원본이 sources/에 저장되고 ZIP 전용 문구의 `unsupported_format` 안내 + [파일 반입으로 이어가기]가 렌더된다 — 조용한 스킵·무한 대기 없음
8. **커버리지 기대치**: "품질경영기사" 검색이 오류 없이 **"공개문제 없음 + 필기·필답형은 범위 밖"** 안내로 끝난다(실측 5). 같은 취지가 어댑터 notice·매뉴얼에 있다
9. 쿼터·키 오류(22·30/31) 상황에서 사람 말 안내 확인 — 원문 XML/JSON 미노출. 같은 검색·목록 반복 조회 시 24h 캐시로 재호출 0건
10. 기존 경로 회귀 없음: 파일·URL 반입(F35-1)·F40 대기열·분류 경로 지정·convert 파이프라인·`GET /images/{filename}`
11. **§6.2 DDL diff 0 · Alembic 마이그레이션 0건 · `sources/` 원본 변경 0건 · `secrets.json` 외 위치에 키 저장 0건**

## 이 단계에서 하지 않는 것

**시험일정 조회 API 연동(`categories.exam_date` 자동 채움)** — 별건 유예(수동 D-Day 등록(S4)으로 충분한지 실수요 확인 후, 계획서 §14 F35-3에 v1.x+ 후보로 기록만),
**qualgbCd C/W 확장**(과정평가형·일학습병행 — T 국가기술자격만),
**서버측 ZIP 해제·HWP 변환**(라이브러리 의존 추가 금지 — 원본 저장 + 파일 반입 폴백으로 충분),
**게시물 `contents` HTML 본문 구조화**(첨부가 정본),
**운영계정 승급·쿼터 관리 UI**(개발계정 일 1,000건이면 충분 — 에러 22 안내로 족함),
**필기·필답형 기출 확보 시도**(이 API에 없음이 실측 확정 — 수동 반입 경로가 정본),
**Q-Net 웹 포털 스크랩·역설계**(오픈API가 대체 — 스텁 유예 건 종결),
**사설 어댑터 재도입**(정책상 금지 — 계획서 §14 F35-2),
**다회차 배치 반입**(한 번에 1회차 유지 — 여러 건은 F40 대기열이 담당하는 수동 경로).
