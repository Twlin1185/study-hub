## 체크리스트

### 1. 블록 스캐너 (신규 유틸 — 순수 함수)

- [x] **1-1. 오프셋 기반 분해**: `scanBlocks(source: string): {start: number, end: number}[]` — 블록 = 원본의 `{start,end}` 반개구간. **블록 텍스트를 이어 붙여 문서를 재구성하는 코드 금지** — 소비자는 항상 `value.slice(start, end)`로 읽고, 치환은 `value.slice(0,start) + draft + value.slice(end)`로만 한다(R28 ① — 스캐너가 틀려도 무편집 문서는 불변).
- [x] **1-2. 분해 규칙**: 빈 줄(공백만 있는 줄 포함 — `trim() === ''`) 구분 + **원자 블록 2종**은 내부 빈 줄을 포함해 한 블록: ⓐ 코드 펜스(```` ``` ````·`~~~` — 여는 펜스와 같은 문자·같은 길이 이상의 닫는 펜스까지) ⓑ `:::` 컨테이너(`:::이름…` 여는 줄부터 짝이 되는 `:::` 닫는 줄까지 — 중첩은 깊이 카운트). **닫히지 않은 펜스·컨테이너는 문서 끝까지 한 블록**(보수적 원자화 — R28 ②). 블록 경계는 줄 단위(블록 start는 줄 시작, end는 줄 끝 또는 개행 전).
- [x] **1-3. 무손실 왕복 자체 테스트**: 대표 케이스(빈 문서·펜스 안 `:::`·닫히지 않은 펜스·연속 빈 줄·CRLF 없음 확인(저장 값은 LF — textarea 관례)·문서 끝 개행 유무)에서 "분해 → 무편집 → 슬라이스 합집합 = 원본 전체·중첩 0·오름차순"을 구현 중 검증하고 결과를 완료 기록에 남긴다(불변 규칙 7 — 실행 스모크 보고. 프론트 유틸이라 pytest 대상 아님).

### 2. 편집 가능 미리보기 서브컴포넌트

- [x] **2-1. 블록 렌더**: 미리보기 모드에서 `scanBlocks` 결과대로 각 블록을 **공용 `MarkdownView`**로 렌더(`docNo`·`scale`·기존 prop 그대로 전달 — 미리보기 전용 렌더 경로 금지). 블록 사이 시각 간격은 기존 미리보기와 유사하게(과한 카드화 금지 — 읽기 모양 유지). 블록 렌더는 내용 기준 메모( `React.memo` 등)로 확정 시 전체 재렌더 비용을 줄인다.
- [x] **2-2. 편집 진입**: 블록의 비인터랙티브 영역 클릭(모바일 탭 동일) → 그 블록만 자동 높이 textarea로 전환, 초기값 = 해당 슬라이스, 포커스. **인터랙티브 요소 클릭은 편집 진입 아님** — `closest('a, button, summary, input, select, textarea, [role="button"]')` 계열 가드(스포일러·fold/hide·임베드 [원문 열기]·링크 동작 유지). 시각적 발견성: hover(또는 포커스) 시 옅은 외곽선 + 커서 표시(토큰 색만 — 불변 규칙 5).
- [x] **2-3. 확정·취소(로컬 초안)**: 편집 중 값은 로컬 초안 — **확정(blur·Ctrl+Enter)** 시에만 원본 구간 치환으로 `onChange` 1회 호출, **Esc = 취소**(초안 폐기·렌더 복귀). 확정 시점에만 블록 재분해(편집 중 다른 블록은 확정 값 기준 고정 — 타이핑 중 블록이 갈라져 편집기가 닫히는 일 금지). 임베드 API도 확정 시점에만 재호출된다(9-6ⓐ 디바운스와 같은 목적을 구조로 달성 — 이 경로에선 디바운스 불요).
- [x] **2-4. 툴바로 포커스 이동 시 확정 방지**: 툴바·셀렉트·참조 삽입 버튼 조작이 blur-확정을 유발하지 않게 mousedown `preventDefault`(또는 `relatedTarget` 판정 — 편집기 크롬 내 이동은 블록 유지). 셀렉트(형광펜 색 등)처럼 포커스를 가져가야 하는 컨트롤은 조작 완료 후 활성 블록 textarea로 포커스 복귀.
- [x] **2-5. 블록 추가·삭제**: 문서 말미(빈 문서 포함)에 "클릭해서 입력…" 자리표시자 블록 → 클릭 시 새 textarea, 확정 시 (앞 블록과) 빈 줄 구분으로 삽입(빈 초안 확정 = 아무 일 없음). 기존 블록 내용을 전부 지우고 확정 = 블록 제거 + 잉여 빈 줄 정리(앞뒤 구분 빈 줄이 이중으로 남지 않게).
- [x] **2-6. 빈 내용 문구**: 문서 전체가 비었을 때 기존 `_미리볼 내용이 없습니다._` 대신 자리표시자 블록이 그 역할을 겸한다(안내 문구는 자리표시자에).
