## 완료 기준 (DoD)

1. 홈 [오늘 공부 시작](분량 예고 포함) → 복습 큐 → 완료 화면("내일 N개") → [이어하기로 계속] → 학습 모드 — **원탭 시작이 끊김 없이** 이어짐. 폰에서는 하단 "복습" 탭으로도 직행
2. 임의 깊이 노드(예: 필기/실험계획법/요인배치법)에서 개념→문제→기출 3단 완주 → 최종 완료 화면. **상위 노드의 [문제]는 하위 전체 문제가 출제**되고 3단 진도·개수 칩이 하위 포함으로 집계됨
3. 퀴즈를 키보드만으로(1~4·Enter) 진행, 오답 직후 틀린이유 원탭이 오답노트에 반영, 정답 자동 다음은 설정대로(오답은 정지)
4. 커리큘럼 탭에서 [+ 문서 추가]로 개념 작성·행에서 편집 저장 — 문서 상세 페이지를 거치지 않고 즉시 반영
5. 태그 관리자: "정규화"↔"정규 화" 유사 쌍 감지 → 병합 → 전 문서 반영. 이름 변경 즉시 반영, 사용 중 태그 삭제는 409, 규칙 사용 배지 표시
6. 검색 "정규형" → "제3정규형" 포함 문서 매칭(trigram), 2자 질의("DB")도 폴백으로 결과. 기존 검색 UI·응답 형태 무변
7. 백업 복원 → 강제 리로드 → **서버 재시작 없이** 복원 데이터로 정상 동작(stale 커넥션 없음)
8. 플래시카드 오판정 → [되돌리기] → 서버 미전송(SRS 상태 무변) 확인
9. 반입 위저드 Stepper — 지나온 단계 클릭 복귀 동작, 미래 단계는 눌리지 않음이 시각적으로 명확
10. Alembic 마이그레이션은 FTS 재구축 1건뿐 — §6.2 DDL diff 0 확인
